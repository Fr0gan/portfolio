CSV & JSON Converter

Turn a spreadsheet export into JSON for code, or JSON back into CSV for a spreadsheet. Quoted fields, commas inside values and Excel's semicolon and tab files are all handled. Everything runs in your browser, and nothing you paste or open is sent anywhere.

Empty Paste CSV on the left, or open a file.

A Lab experiment, written in plain JavaScript. The CSV reader follows RFC 4180: fields in double quotes can hold separators, line breaks and doubled quotes. Numbers with leading zeros, such as ZIP codes, stay as text so they aren't changed. When JSON objects have different keys, every key gets a column, and nested values are written as JSON inside the cell. View source · More Lab experiments
