How it works

Every character or word is picked with crypto.getRandomValues, the browser's cryptographically secure random number generator, using rejection sampling so no choice is more likely than another.

Strength is shown in bits of entropy: the number of yes-or-no guesses an attacker would need in the worst case. Each extra bit doubles the work. Aim for at least 60 bits, and use a password manager so you don't have to remember them.
