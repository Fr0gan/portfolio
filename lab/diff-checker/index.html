Diff Checker

Paste two versions of some text or code to see exactly what changed, line by line and word by word, then copy the changes as a patch. Everything runs in your browser. Nothing you paste is sent anywhere or saved.

Changes

A Lab experiment, written in plain JavaScript. Lines are matched with a longest-common-subsequence diff after trimming the parts that are the same at the start and end, then each changed pair of lines is compared word by word. Patches use the standard unified diff format, so tools like patch can apply them. View source · More Lab experiments
