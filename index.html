Game · HTML Canvas

Slime Blaster

An arcade shooter rebuilt from my GameMaker game. The player holds a lane against waves of enemies that speed up the longer the run lasts.

  • Delta-time game loop with sprites drawn from pixel maps
  • Collision detection, difficulty scaling and health pickups
  • Keyboard and touch controls; high score saved locally
  • JavaScript
  • Canvas API
  • localStorage

Game · Reaction timing

Samurai Duel

A reaction-time game modeled on the standoff scenes in classic samurai films. Wait for the signal, then strike before the opponent does, across six difficulty tiers.

  • Explicit state machine: ready, waiting, signal, result
  • Reaction times measured with performance.now()
  • Scene and duel animations written entirely in CSS
  • JavaScript
  • CSS animation
  • SVG
Play demo → Source

Game · DOM

Memory Match

A card-matching game with three difficulty levels, a move counter, a timer and a saved best result for each level.

  • Fisher–Yates shuffle for an unbiased deal
  • 3D card flips using CSS transforms
  • Real buttons with screen-reader labels for every card
  • JavaScript
  • CSS 3D transforms
  • ARIA
Play demo → Source

Tool · Text input

Speed Typer

A typing speed test with 15, 30 and 60-second modes, live words-per-minute and accuracy, and personal bests.

  • WPM counts only correctly typed characters
  • Built on input events, so it works with phone keyboards
  • Measured caret placement and automatic line scrolling
  • JavaScript
  • DOM measurement
  • localStorage
Try it → Source

Tool · Graphics

Pixel Studio

A pixel-art editor with pencil, eraser, fill and color picker tools, mirror mode, two canvas sizes and PNG export.

  • Flood fill and Bresenham line drawing for gap-free strokes
  • Undo and redo history with keyboard shortcuts
  • Autosaves the drawing between visits
  • JavaScript
  • Canvas API
  • Algorithms

About

Since then I've been building for the browser with plain HTML, CSS and JavaScript. I like writing small, dependency-free code and making sure things work on phones as well as desktops.

Outside of programming I enjoy hiking, card games and classic samurai cinema.
